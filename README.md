# 🛒 UMKM E-Commerce & Point of Sale System
---

## ✨ Features

### 👤 Authentication & Roles
- Multi-role system (Admin, Seller, Customer)
- Secure login & registration
- Profile management

### 🛍️ Customer Features
- Browse products
- Add to cart
- Checkout system
- Order history

### 🧑‍💼 Seller Dashboard
- Product CRUD
- Manage orders
- Sales statistics dashboard

### 🛠️ Admin Panel
- User management
- Product management
- Transaction monitoring

---

## ⚙️ Tech Stack

- Laravel 10+
- PHP 8+
- MySQL / MariaDB
- Bootstrap UI
- Vite
- Midtrans Payment Integration
